## Precedence (stable rule)

Sources are ranked by played length. The longest is the base of every phase and is kept as recorded. Each shorter source, in order of played length, only adds records in cells (1100 units) and phases that no higher-ranked source covered (a capture covers the cells in its view during that phase, a world file the cells of its records), never within the candidate's collision distance of a higher-ranked record (hosted_config `game.collide_by_def`, else the game_config.js family value, at least 80), and never overrides, moves or removes a higher-ranked record. A world file only feeds the phase of its `biome`. Synthetic fill comes last, only in cells still mostly unseen and holding no lower-ranked record. Every record carries `source` = its source id (`synthetic` records also keep `synthetic: true`). Player builds and unknown defs are dropped from every source.

## Biomes are timed phases, each with its own layout

No spatial biome map exists. The server sends a timer message (sp5 type 71, atl4 type 32) `{b, d}`: `b` = phase, `d` = ms left; the client re-themes the ground from `b` itself (bundle: the timer handler calls the theme switch: background colour plus one of six ground decal sets, each spread over the whole map). At every switch the objects of the new phase appear at NEW positions (0 of the new objects in a switch frame sit on an old object's spot; median distance to the nearest old object 146 to 449 units), so each phase is its own layout on the same coordinates. The capture is cut into phase windows by the timer messages and each phase is stitched only from its own window.

## Synthetic

Per phase, cells at least half unseen in that phase get objects flagged `synthetic: true` at 50% of that phase's observed density (all capture sources), defs drawn from the phase's own real capture objects (no gifts), >= 260 units apart, never inside his seen area for that phase (seed 5). They sit in `phases[b].synthetic` and are appended to the top-level `objects` for the default phase. `--synth 0` gives a real-only world.
